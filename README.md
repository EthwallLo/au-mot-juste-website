# Au mot juste

Site vitrine de Lorena Guedouani, correctrice-relectrice freelance. Il présente ses prestations de correction, de relecture et de traduction anglais-français, avec un blog et une newsletter.

## Technologies

- Next.js, React et TypeScript
- Tailwind CSS et CSS Modules
- PostgreSQL : Neon en production et PGlite en local
- Nodemailer pour les e-mails
- Vercel pour l’hébergement, avec Blob et Workflows
